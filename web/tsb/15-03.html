Smart Tech II Automatic Transmission Fluid Exchanger Machine

New95850

MOC has released the Smart Tech® II ATF fluid exchanger machine.

Download PDFView PDFAll bulletins

What's new

The following configurations of this machine are now available.

A Smart Tech® II upgrade kit is also available. This kit will upgrade an existing Smart Tech® ATF machine to the new Smart Tech® II machine.

Key benefits

  • Improved accuracy. The machine utilizes new float level sensor technology.
  • Automatically adjusts. This machine automatically adjusts for the technician's chosen dipstick service adapter.
