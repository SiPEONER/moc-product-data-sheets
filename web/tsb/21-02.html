MAP Sensor Adapters For Induction Services

New7344873449

MOC has created two new adapters that make induction services easier with the EDR-3 machine through the MAP sensor port, keeping the MAP sensor connected to the vehicle during the service. This may help hold the engine at the recommended RPM.

Download PDFView PDFAll bulletins

What's new

These adapters can only be used with the EDR-3 machines.
