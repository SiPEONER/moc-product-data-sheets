Fuel Pump Bypass Tool For Vehicles with Returnless Fuel Systems

New7305572450

MOC has developed a new tool (Part No. 73055) for use with the Cleaner Application Tool (Part No. 72450) to service vehicles with returnless fuel systems, which are found in most vehicles today. There is no longer a need to disable the fuel pump on vehicles with returnless fuel systems. The use of this new tool, in addition to other MOC fuel adapters, allows for fuel injector services via the fuel rail. Complete user instructions are included with each tool.
