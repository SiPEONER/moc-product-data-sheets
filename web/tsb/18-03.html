Conversion Kit for the Air Operated Coolant Machine

New95335

MOC has developed a new kit to convert an existing MOC Coolant Machine into the new Air Operated Coolant Machine. This easy to install kit allows the customer to take an existing Single Pump Coolant Machine or Double Pump Coolant Machine and convert it to the new Air Operated Coolant Machine. The conversion requires replacement of the internal components while utilizing the existing chassis and fluid tanks. The kit comes with step by step, color coded, user instructions.
