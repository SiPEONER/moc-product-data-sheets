EGR Tool for Ford 6.7L Diesel Engines

New72330

MOC has developed a new tool to clean the Ford 6.7L Diesel EGR valves and coolers. This tool is designed to be used when performing services with our Optimizer™ Foaming Combustion Chamber & Emission System Cleaner, and is easy to install. User instructions are included with each tool.
