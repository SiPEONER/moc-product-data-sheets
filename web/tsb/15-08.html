Cleaner Application Tool Changing

72450

The MOC Machine and Equipment Department is changing the Cleaner Application Tool by reducing the size of the canister. This change will reduce the overall height of the tool by 2½in. and reduce the weight of the tool by 8oz.

Download PDFView PDFAll bulletins

What's new

The current version of this tool weighs 4.21lbs and is 17in. tall. The new revision of this tool weighs 3.71lbs and is 14.5in. tall.

The current version of this tool has a fluid capacity of 26oz. The new revision of this tool has a fluid capacity of 18oz.

The new changes will be implemented after the inventory of the current Cleaner Application Tool (4.21lbs / 17in.) is depleted.

Contact

For more information, contact the Machine & Equipment Department at 866.244.6621.
